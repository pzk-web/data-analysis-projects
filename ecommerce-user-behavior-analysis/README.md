# 电商用户行为分析：转化漏斗与用户分层

基于淘宝用户行为公开数据集，使用 MySQL 取数、Python 完成转化漏斗分析、RF 用户分层与商品类目效率分析，并将结果可视化。

## 一、项目背景

电商运营团队希望回答三个问题：

1. 用户从浏览到购买的转化链路在哪里流失？
2. 不同价值的用户如何分层，分别应该采取什么运营策略？
3. 哪些商品类目转化效率高，哪些类目高曝光却零成交？

## 二、数据集说明

- **来源**：阿里淘宝用户行为公开数据集（抽样 10 万条行为记录）
- **时间范围**：2014-11-18 ~ 2014-12-18（约一个月）
- **数据表**：`user_behavior_new`

| 字段 | 含义 |
|---|---|
| user_id | 用户 ID |
| item_id | 商品 ID |
| behavior_type | 行为类型：1 浏览 pv / 2 加购 cart / 3 收藏 fav / 4 购买 buy |
| item_category | 商品类目 ID |
| time | 行为时间（精确到小时） |

> 出于体积与数据规范考虑，原始 CSV 未纳入本仓库，字段结构与导入方式见 [`data/README.md`](data/README.md)。

## 三、分析框架

| 模块 | 分析内容 | 关键产出 |
|---|---|---|
| 数据概览 | 四类行为的次数与占比分布 | 行为分布柱状图 |
| 转化漏斗分析 | 浏览 → 加购 → 收藏 → 购买，层层包含的用户数与逐级转化率 | 转化漏斗图 |
| RF 用户分层 | 按最近购买间隔 R 与购买频次 F 交叉分群 | 分层分布图、R-F 四象限散点图 |
| 商品类目效率 | 各类目浏览/购买用户数与转化率，识别高转化与高曝光零成交类目 | 类目转化对比图 |

## 六、本地运行

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 在 MySQL 中创建数据库 `taobao_analysis`，按 [`data/README.md`](data/README.md) 准备数据并运行导入脚本：

   ```bash
   python scripts/import_data.py
   ```

3. 修改 `main.ipynb` 开头的数据库连接配置（账号、密码、端口）。

4. 启动 Jupyter 并打开 `main.ipynb` 顺序运行即可。

## 七、核心结论摘要

- **转化漏斗**：浏览 → 加购转化率约 36%，是链路中流失最严重的环节；加购 → 收藏 61%、收藏 → 购买 65%，中后段用户购买意向较强；整体浏览 → 购买转化率约 14.6%。
- **用户分层**：899 个行为用户中，购买用户 426 人，分为重要价值用户 142、新客待发展 72、重要挽留用户 85、流失用户 127；另有潜在未转化用户 473 人。
- **类目效率**：共 3811 个类目，仅 514 个产生购买；部分类目浏览人数多但零成交，另有一批转化率约 10% 的高转化类目可倾斜流量。
- **高意向信号**：购买用户 74.2% 有收藏行为，未购买用户仅 45.5%；加购且收藏用户购买率 65.2%，加购未收藏仅 34.1%。成交用户人均浏览 139.4 条、收藏 4.5 次，约为未成交用户（74.3 条、1.6 次）的两倍。
- **加购拆解**：327 名加购用户成交 174 人（53.2%）；未成交者收藏 1.5 次、浏览 121.7 条，明显低于成交者的 5.1 次、204.5 条。
- **类目分层**：零成交类目中仅 12 个属高曝光（浏览≥50 人）且均有加购 / 收藏信号，其余 3285 个为长尾低曝光，无需投入。
- **决策周期**：购买用户中位决策约 9.9 天、均值 11.4 天，58.9% 成交发生在首次行为 7 天以后，需分阶段持续召回。

## 八、数据局限

- 分析基于抽样 10 万条样本，结论反映样本结构，不等同于全量大盘。
- 数据集缺少消费金额字段，未做 RFM 中的 M（金额）维度，仅采用 RF 两维分层。
- 时间字段精确到小时，R 指标按天粒度计算。
